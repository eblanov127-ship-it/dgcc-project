SpendWise Web Demo

This is a static web adaptation of the provided SwiftUI project, for presentation/demo purposes.
All displayed spending values and transactions are sample data. The web demo has responsive layout and clickable detail popups.

Deploy with Vercel:
1. Create a GitHub repository and upload these files (index.html, icon.png, README.txt).
2. Go to https://vercel.com and sign in with GitHub.
3. Add New -> Project, select the repo.
4. For a plain static site, keep framework preset as Other (or no framework), Build Command empty, Output Directory empty / root.
5. Deploy. Vercel gives a public URL.
6. Share the URL or generate a QR code to it for the presentation.
